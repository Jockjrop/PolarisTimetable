# Polaris 1.27.12

- 桌面小组件新增「本周课表」视图（WakeUp 风格，与既有今日课表并列）：大字号日期与周信息头、双行表头突出今日列、课程名与地点随格内联展示，周六/周日列可按需隐藏；多课表场景按所有已绑定课表汇总刷新边界，配套新增刷新调度器，避免跨天/跨周后组件内容停留过期状态。
- 小组件关闭态改为「未启用」提示视图：不再以透明占位隐藏，用户在桌面可明确看到开关入口，避免误解组件损坏。
- 「我的」下全部设置子页面（课表设置/全局设置/安全设置/用户信息/更多）视觉区分优化：
  - 设置卡提亮并与页面底色拉开明度差，边缘补浅蓝灰描边，卡片边界清晰可辨；
  - 卡片内行与行之间增加与文字对齐的细分隔线，多行设置项不再糊成一块；
  - 长文本值（官方网站、反馈邮箱等）不再在固定列宽内畸形断行，改为占满剩余宽度、最多两行省略；
  - 章节标题改为带字距的紧凑标签并与卡片内文字对齐，层次更清楚。
- 课表面板移除节间横向网格线，版面更清爽。
- 为周视图日期推算与跨周边界新增单元测试回归（ScheduleWidgetWeekDataTest），覆盖 5/7 天模式与周末隐藏。
