# Polaris 1.27.12

## 桌面小组件

- 新增「本周课表」小组件形态（WakeUp 风格），与既有「今日课表」并列可选：整周按「节次行 × 天列」网格铺排，与应用内课程表同款布局语义；表头双行（单字星期 + 日期号）突出今日列，配大字号日期与「课表名 | 第 N 周 周X」信息头。
- 周视图格子按课程色渲染圆角色块，课程名与地点内联展示为「课名 @地点」，跨节课程在覆盖的每个节次行重复占格；空格格隐藏底图，保持网格呼吸感；整周列表支持在小组件内上下滑动，并补全无障碍内容描述与空状态视图。
- 今日/明日表单形态保留；刷新调度统一抽为独立调度器：课程上下课边界闹钟、跨天/时间/时区变更/开机广播统一驱动今日与整周两种形态同步刷新，多课表仍按所有已绑定课表汇总最近边界（沿用 1.27.11 行为），任一形态移除实例时闹钟链自动接续，不中断另一形态。
- 整周形态显示天数可选（周一至周五 / 加周六 / 加周日），配置页新增天数档位并按小组件实例独立记忆，默认 5 天。
- 新增桌面小组件总开关（全局设置）：关闭后已放置的今日/整周小组件统一渲染为「已关闭」占位视图（不再是透明隐藏），并取消刷新闹钟；重新开启立即恢复刷新。开关切换后弹出操作指引，说明如何从桌面添加/移除小组件（应用无法代删桌面组件）。
- 固定 1.27.11 遗留风险：多课表用户各实例绑定不同课表时，整周形态标题正确显示「课表名 ·」前缀以分辨数据源。

## 设置与视觉

- 顶/底栏样式新增「默认 / 常规」选择（全局设置 → 高级）：默认保持悬浮玻璃（圆角、页边距、平板横屏与网格对齐）；常规为贴边通栏矩形（顶栏贴顶、底栏贴底、圆角归零，仅保留状态栏/导航条避让），样式切换即时生效并持久化。
- 「我的」下全部设置子页面（课表设置/全局设置/安全设置/用户信息/更多）视觉区分优化：
  - 设置卡提亮并与页面底色拉开明度差、边缘补浅蓝灰描边（此前卡片与浅蓝页面明度差不足 0.5，边界不可辨）；
  - 卡片内行与行之间增加与文字对齐的细分隔线，多行设置项不再糊成一块；
  - 长文本值（官方网站、反馈邮箱等）不再在固定列宽内畸形断行（如网址断出孤立尾行），改为占满标签剩余宽度、最多两行省略；
  - 章节标题改为带字距的紧凑标签并与卡片内文字对齐，层级更清楚。
- 课表面板移除节间横向网格线，版面更清爽。

## 测试与工程

- 为整周小组件日期推算与 5/6/7 天模式新增单元测试回归（ScheduleWidgetWeekDataTest），覆盖周末列隐藏与第 N 周计算。
