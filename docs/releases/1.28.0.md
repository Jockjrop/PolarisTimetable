# Polaris 1.28.0

- 新增节假日与调休支持：内置 2026 年国家法定节假日安排，放假日课表列标记「休」且不再排课，今日概览与桌面小组件同步提示。
- 支持按学校安排指定补班日所对应的课程，课表列标记「补」；未指定时按实际星期显示，并在设置中提示待确认项，避免误排。
- 新增「全局设置 → 节假日与调休」配置入口，可逐项调整或一键恢复内置安排；相关设置仅保存在本机，不会上传。
- 课前提醒、iCal 日历导出及今日/整周桌面小组件同步节假日与调休：假期不触发提醒、不生成日历事件，补班课程按目标日期正确排入。
- 课表分享改为加密链接与二维码，取代原有课表文件；链接中课程信息不以明文呈现，亦不含账户资料与设备标识，被改动后将拒绝解析，旧版文件与早期链接仍可导入。该链接用于避免内容被直接查看，不等同于端到端加密，请勿用于传递敏感信息，详见隐私政策。
- 导入方式扩展为应用内扫码、相册识别二维码与剪贴板粘贴，并补充相机权限说明；无相机设备或拒绝授权时，仍可通过粘贴或相册完成导入。
- 二维码支持保存至相册或直接分享图片，保留必要的空白边缘，深色主题下同样可正常识别；分享弹窗重新排版，链接支持点击复制，四项操作分区呈现。
- 优化整周课表小组件：连堂课程的课程名称、任课教师与上课地点按整块课程格自上而下依次排布，续段信息不再留白，长名称显示更完整。
- 整周课表小组件同步节假日与调休数据：放假日对应列留空，补班日按指定星期显示课程，表头标记「休」「补」；无障碍朗读补充教师与地点信息。
- 平板横屏新增「计划」导航入口，恢复课表、计划、我的三 tab 结构；课表列宽与节次高度按屏幕空间调整，三块侧栏可同屏完整呈现，单屏可见节次更多，底部导航不再遮挡课程内容。
- 修复切换视觉主题后设置页回到顶部、已展开分组被收起，以及用户所选深色/浅色模式被覆盖的问题；「我的」页改用统一布局，四套主题保持一致的页面结构。
- 优化顶栏「···」入口：改为常驻圆角方框并补充按压反馈，与同行控件对齐；操作菜单改为随入口锚定显示，位置保持固定。
- 更新官方网站地址至 https://timetable.deeps.top/，同步「关于」与反馈入口，并完成官网页面改版。
