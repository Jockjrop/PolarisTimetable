# UI 回归清单（阶段 0/6 基线，1.15.0 更新）

> 用途:UI 重构各阶段交付前的人工冒烟基准。每项默认在手机竖屏验证,标注【平板】的另需平板/横屏验证。
> 基线截图:`build/verify_*.png`（每批 `assembleDebug` 后更新），重构开始前存档于发布记录,对照检查视觉无意外回归。
> 当前基线 `1.15.0`：`verify_11500.png` 空态顶栏/底部导航、`verify_11403_settings.png` 课表设置开关、`verify_11406.png` 空态，`testDebugUnitTest` 必须 `BUILD SUCCESSFUL`。

## 1. 主流程

- [ ] 冷启动进入课表页,顶部栏、周课表网格、底部导航完整显示
- [ ] 周切换(上一周/下一周/回到本周)正常,日期头随周更新
- [ ] 点击课程块弹出课程详情,信息完整
- [ ] 编辑课程、删除课程(单次/本门课)正常
- [ ] 【平板】横屏双栏布局:课表在左,今日概览/实践/计划面板在右

## 2. 系统栏与 insets(阶段 2 重点)

- [ ] 状态栏区域:背景与页面背景连续,无白条/黑条,顶栏文字不被状态栏遮挡
- [ ] 手势导航(全面屏手势):底部导航条不被手势区遮挡,可正常点击
- [ ] 三键导航:底部导航完整可见
- [ ] 挖孔屏/刘海屏:竖屏顶栏不被挖孔遮挡;【平板】横屏内容不被侧边挖孔遮挡
- [ ] Android 15(API 35)设备/模拟器:同上全部通过(该系统强制 edge-to-edge)
- [ ] Android 10~14 设备:视觉与 Android 15 一致(背景延伸到系统栏后方)
- [ ] 暗色模式:状态栏图标自动切换明暗,背景无违和色块

## 3. 对话框与键盘

- [ ] 课程编辑器:全屏打开,顶部/底部不被系统栏遮挡
- [ ] 课程编辑器:点击课程名等输入框,键盘弹出后输入框可见,可正常输入并收起
- [ ] 设置页各弹窗、导入预览弹窗正常打开/关闭

## 4. 导入与导出(核心流程,任何阶段不得破坏)

- [ ] 导入教务系统 PDF:解析 → 预览 → 确认,课程出现在周课表
- [ ] 分享 .polaris.schedule 文件导入正常
- [ ] 导出图片/PDF/ics 正常

## 5. 字号与本地化(阶段 3+ 验收用)

- [ ] 系统字体大小"最大"(fontScale 1.3x):文字不截断、不溢出卡片
- [ ] 显示大小"最大":布局不塌陷
- [ ] 伪本地化(en-XA,开发者选项):无硬编码中文残留、无截断

## 6. 旋转与重建(阶段 4/6 验收用)

- [ ] 手机竖屏 ↔ 横屏旋转:布局正确重建,当前周/页签保持
- [ ] 旋转时正在编辑课程的对话框关闭后状态不丢失
- [ ] 平板分屏/自由窗口:以任意尺寸缩放,布局自适应
- [ ] 进程被杀后冷启动:课表数据、当前周恢复

## 7. 主题(每次交付)

- [ ] 四套视觉主题(极简/极光/深空/云境)× 明暗:课表网格、卡片、系统栏均正常
- [ ] 自定义背景图:裁剪、模糊正常,课程块可读性不下降

## 8. 矩阵（阶段 6 收口，1.15.0 基线）

- [ ] 字号 1.3x/2.0x：`ScheduleBoardView` 长课程名换行/`ellipsize`，`CourseEditorDialog` 按钮两行，`verify_11500` 在 `fontScale 1.3` 下不截断
- [ ] RTL `ar-XB`：`Gravity.RIGHT` 已收敛为 `START/END`，`ConstraintLayout` 自适应
- [ ] 旋转/重建：`configChanges=orientation|screenSize|smallestScreenSize` 下 `buildLayout()` 全量重建，`ViewBinding onDestroyView` 置空
- [ ] 长课程名/多节叠加：`Board` 的 `conflict` 角标 + `+N` 折叠
- [ ] 平板/折叠/分屏：`TABLET_SETTINGS_SPLIT=425` `PRACTICE_PANEL_WIDTH=190` `PLAN_PANEL_WIDTH=360` 在 `1080×2400` 与 `1280×800` 平板验证
- [ ] 触控：`BottomNavView` `48dp` 高度，`settingsGroup` 行 `58dp`
- [ ] 对比度：`inkColor/mutedColor` 在 `pageSurfaceColor` 上 `WCAG AA`
- [ ] 焦点顺序：`TopPanel` 周选择器 → `Board` → `BottomNav` → `MyPage` 四卡片
