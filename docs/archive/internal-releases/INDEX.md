# 内部迭代记录（未单独发布）

> 本目录保存 2026-09-14 线上稳定版 `v1.27.14` 之后、2026-11-13 合并发布 `1.28.0` 之前的**本地内部迭代发布说明**。
> 这些版本**从未推送到 GitHub / Gitee，也没有打过标签、没有生成过稳定清单**，只用于记录开发过程；它们不是对外发布版本，不应被理解为「1.28.0 之后还有 1.30.x」。
> 对外更新说明以 [`docs/releases/1.28.0.md`](../../releases/1.28.0.md) 为唯一来源，版本历史以根目录 `CHANGELOG.md` 为准。
> 本目录逐版说明中的「修复」多属开发过程（该轮改动引入、下一轮修掉，例如导入长链接光标位置、窄列换行、菜单跳位、章节标题着色等），**不作为对外发布说明条目**；对外说明只写相对线上 `v1.27.14` 真实存在的新增、优化、改进与修复。

## 为什么合并

发布流水线（`.github/workflows/build.yml`）以 `docs/releases/<versionName>.md` 生成 `latest.json` 并校验 `versionCode` 严格大于上一稳定清单。线上 `latest.json` 最后停在 `1.27.14 / 12714`。本地在此期间连续迭代了多个版本号但未走发布流程，若按 `1.30.6 / 13006` 直接发布会让更新说明、CHANGELOG 与 GitHub Release 三者对不上；因此统一回并为一个对外版本 `1.28.0 / 12800`，仍严格大于线上 `12714`。

## 归档时保留的结论

- 课程格子高度默认 **66dp**（1.27.9 起，用户确认值），横屏平板 1.30.3 从 82dp 回到该默认值，勿回退。
- 加密链接比明文长约 6%（实测 438 → 467 字符），来自 AES-GCM 盐 / IV / 认证标签固定 36 字节开销；字典化压缩反而使 deflate 输出变大，已回退。
- 顶栏「···」按钮是 `showAsDropDown` 的菜单锚点，**任何按钮自身 transform 动画都会导致菜单跳位**，动效只能作用于 Canvas 内部绘制。
- 节假日内置表 `res/raw/holidays.json` 每年需随国务院安排更新一次；CSV 导出是「星期 + 周次」模板，不含具体日期，不受节假日影响。
