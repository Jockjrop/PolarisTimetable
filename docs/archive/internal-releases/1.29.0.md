# Polaris 1.29.0

- 课表分享改为**加密链接**：不再生成 `.polaris` 文件，直接在应用内显示二维码与链接，可复制或通过任意应用发送
- 导入侧同步改为**粘贴链接**：菜单入口由「导入课表文件」改为「导入课表链接」，弹窗支持从剪贴板一键粘贴，解析后走与深链相同的确认流程
- 新增**扫一扫**：应用内直接调用相机识别二维码，界面锁定竖屏，识别到链接即进入导入确认
- 新增**相册导入**：从系统图片选择器选一张二维码截图，本地解码导入；图片按长边缩到 800px 再识别，避免大图 OOM
- 链接内容先用紧凑二进制打包、deflate 压缩，再做 AES-256-GCM 加密；同一份课表每次生成的链接都不同（随机盐与 IV）
- 链接不含课程明文、账户名、学校与设备标识；链接被改动一个字节即校验失败，不会导入半截数据
- 旧格式仍然兼容：已收到的 `.polaris` 文件与 1.28 及更早生成的 `polaris://` 链接都能正常导入
- 二维码为白底深码、固定纠错级别 M，深色主题下也能正常识别
- 分享弹窗提供「复制链接」与「发送链接」两个入口，长链接自动中间省略显示
