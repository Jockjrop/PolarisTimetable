# Polaris 1.30.0

- 分享弹窗重做：二维码放进白色圆角卡片，链接文本改为可点击复制的色块，底部四个操作分两行排布
- 新增**保存到相册**：二维码渲染成 720×720 PNG 存入 `Pictures/Polaris`，Android 10 起走 MediaStore 无需权限，更低版本按需申请存储权限
- 新增**分享二维码**：直接把二维码图片交给系统分享面板，可发到微信、信息、邮件等任意应用
- 二维码四周补齐 4 个模块的静默区，保存成图片后贴边识别也不会失败
- 修复「···」菜单位置漂移：改用 Dialog 定位，菜单每次固定在按钮正下方，不再出现位置对不上的情况
- 修复菜单背景整块透明：玻璃底色在独立窗口里取不到背景源，改为不透明卡片色
- 导入弹窗说明文案精简为「扫码、选图或粘贴链接都可以」
