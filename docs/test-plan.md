# Polaris课程表测试计划

## 1. 测试目标

测试计划覆盖 PDF 解析、周次规则、UI 适配、导入失败和状态切换。目标是让每个阶段都有可验收的质量标准，而不是等全部重构后再补测试。

## 2. PDF 解析测试

### 示例 PDF 基准测试

测试文件：

- `苏国强(2025-2026-2)课表.pdf`

验证点：

- PDF 可打开。
- 页数识别为 2 页。
- 能提取文字。
- 能识别学期文本 `2025-2026学年第2学期`。
- 能识别星期一到星期五。
- 能识别至少 1-8 节中的课程。
- 能提取课程名、周次、地点、教师。

验收标准：

- 解析结果非空。
- 普通课程不重复。
- 低置信度项目有警告而不是静默失败。

### 非文字 PDF 测试

测试场景：

- 扫描版 PDF。
- 图片转 PDF。

验收标准：

- 返回 `NO_TEXT_FOUND` 或 `UNSUPPORTED_SCANNED_PDF`。
- UI 提示“当前只支持文字型 PDF”。
- 不崩溃。

### 损坏 PDF 测试

测试场景：

- 空文件。
- 扩展名为 PDF 但内容不是 PDF。
- 打不开的 URI。

验收标准：

- 返回 `PDF_OPEN_FAILED`。
- 显示重新导入按钮。
- 保留上一次成功课表。

## 3. 周次解析测试

输入和期望：

```text
1-18周 -> RANGE 1..18
1-17周(单) -> ODD 1..17
2-18周(双) -> EVEN 2..18
9-16周 -> RANGE 9..16
项目周 -> PROJECT
周次见PDF -> UNKNOWN
```

验证点：

- `containsWeek(1)` 对 `1-17周(单)` 为 true。
- `containsWeek(2)` 对 `1-17周(单)` 为 false。
- `containsWeek(18)` 对 `2-18周(双)` 为 true。
- `UNKNOWN` 课程默认显示但标记低置信度。

## 4. 星期列识别测试

测试场景：

- 标准标题：星期一到星期五。
- 包含星期六、星期日。
- 标题缺失但课程坐标明显。
- 标题识别不完整。

验证点：

- 列中心横向跨度合理。
- 最近列匹配不会把周一课程识别到周二。
- fallback 策略会记录诊断日志。

示例 PDF 参考：

- 星期一中心约 197。
- 星期二中心约 337。
- 星期三中心约 477。
- 星期四中心约 616。
- 星期五中心约 756。

## 5. 节次识别测试

测试输入：

```text
(1-2节)1-18周
（3-4节）1-17周(单)
(5 - 6节)2-18周(双)
(7-8节)1-15周(单)
```

验收标准：

- 正确解析开始节次和结束节次。
- 中文括号和英文括号都支持。
- 空格不会影响识别。
- 超出合理范围时产生警告。

## 6. 课程合并测试

测试场景：

- 同一课程不同时间：合并为一个 `Course`，多个 `CourseMeeting`。
- 完全重复的课程块：只保留一次。
- 同名不同教师：不强行合并。
- 同名同教师但单双周不同：同一课程下保留不同 meeting。

验收标准：

- 周课表展示仍按 meeting 展开。
- 课程详情能展示多个上课时间。
- 合并前后数量写入诊断日志。

## 7. UI 尺寸适配测试

设备范围：

- 小屏手机：360x640 dp。
- 常见手机：393x852 dp。
- 大屏手机：430x932 dp。
- 7-8 寸平板。
- 10-11 寸平板。

验证点：

- 顶部标题不遮挡按钮。
- 统计卡片文字不溢出。
- 课程块在最窄列宽下仍可读。
- 底部导航高度稳定。
- 横向滚动可访问所有星期。

## 8. 导入失败测试

测试场景：

- 用户取消文件选择。
- URI 权限失效。
- 文件读取中断。
- PDFBox 抛出异常。
- 解析结果为空。

验收标准：

- 用户取消不显示错误。
- 权限失效显示可理解提示。
- 解析为空时显示“未识别到课程”。
- App 不崩溃。

## 9. 空课表测试

测试场景：

- 首次安装。
- 用户清空课表。
- 当前周没有任何课程。

验收标准：

- 首次安装展示示例课表和导入入口。
- 清空后显示空状态。
- 当前周无课显示“本周没有课程”，不误认为没有导入。

## 10. 横竖屏切换测试

测试场景：

- 解析中旋转屏幕。
- 课表页旋转屏幕。
- 详情弹窗打开时旋转。

验收标准：

- 不崩溃。
- 当前周次不丢失。
- 已导入课程不丢失。
- 弹窗可关闭或正确重建。

## 11. 平板适配测试

测试场景：

- 平板竖屏。
- 平板横屏。
- 分屏模式。

验收标准：

- 课表列宽增加。
- 周视图尽量铺满屏幕。
- 弹窗宽度不超过合理范围。
- 底部导航不被系统栏遮挡。

## 12. 导出和分享测试

阶段 5 开始执行。

测试场景：

- 导出本周图片。
- 导出空课表。
- 分享到微信、QQ、系统文件。
- 导出 PDF。

验收标准：

- 图片清晰、不裁切。
- 分享文件 URI 可被外部应用读取。
- 无课程时给出提示。
- PDF 页面内容不重叠。

## 13. 回归测试清单

每个阶段完成后至少检查：

- App 能启动。
- 示例课表能显示。
- PDF 选择器能打开。
- 示例 PDF 能解析。
- 周次切换可用。
- 点击课程不崩溃。
- 横竖屏不崩溃。
- 低端小屏不出现明显遮挡。
