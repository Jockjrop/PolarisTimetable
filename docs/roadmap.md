# Polaris课程表开发路线图

> **归档说明（2026-08-31）**：本文件的阶段 1–5 已于 `1.4.0`–`1.15.2` 期间全部落地（PDF 解析增强、`MainActivity` UI 拆分、本地保存与编辑、导出分享提醒、UI 重构阶段 0–6）。路线图已由 [`docs/iteration-plan.md`](iteration-plan.md) 接替，本文件仅作历史记录，**不要再据此排期**。

## 阶段 1：稳定当前功能

目标：

- 保持 PDF 导入和课表展示可用。
- 修复明显 bug。
- 提取 model 和 parser 的设计边界。
- 不改变 UI 外观。

改动范围：

- 小范围整理 `MainActivity` 中的常量和示例数据。
- 为解析结果增加最小错误信息。
- 可新增模型类，但不强制替换全部旧代码。
- 可新增 parser 包壳层，但旧 `ScheduleParser.parse()` 保持可用。

不应该改的地方：

- 不重写 UI。
- 不迁移 Kotlin 或 Compose。
- 不删除 `MainActivity.java`、`Course.java`、`ScheduleParser.java`。
- 不改变导入 PDF 的主流程。

验收标准：

- 打开 App 能看到示例课表。
- 点击导入 PDF 能选择文件。
- 示例 PDF 能解析并显示课程。
- 周次切换按钮仍可用。
- 横竖屏切换不崩溃。

测试重点：

- 示例 PDF 导入。
- 空状态展示。
- 解析失败 Toast 或错误提示。
- 手机和平板基础布局。

## 阶段 2：优化 PDF 解析

目标：

- 提高识别准确率。
- 增加解析日志。
- 增加解析失败提示。
- 增加示例 PDF 测试。

改动范围：

- 拆出 `PdfTextExtractor`、`TextBlock`、`DayColumnDetector`、`SectionDetector`。
- 新增 `WeekRuleParser`。
- 增加 `ParseDiagnostics`。
- 增加 `ParseResult` 和 `ParseError`。
- 对当前示例 PDF 建立解析用例。

不应该改的地方：

- 不改主 UI 风格。
- 不做 OCR。
- 不引入大型依赖。
- 不把解析迁移到后端。

验收标准：

- 能识别示例 PDF 中第一页和第二页课程。
- 能识别单周、双周、普通周次。
- 地点和教师字段提取稳定。
- 解析失败能给出明确原因。
- 诊断日志可查看或复制。

测试重点：

- 星期列识别。
- 节次正则。
- 课程名换行。
- 地点/教师提取。
- “其他课程”不误识别为普通网格课程，或作为独立低置信度结果处理。

## 阶段 3：重构 UI

目标：

- 将 `MainActivity` 中的 UI 绘制拆分。
- 增加课程详情弹窗。
- 增加今日概览卡片。
- 完善手机和平板适配。

改动范围：

- 新增 `ui/ScheduleBoardView`。
- 新增 `ui/TodayOverviewView`。
- 新增 `ui/CourseDetailDialog`。
- 新增空状态和错误状态 View。
- MainActivity 只协调状态和事件。

不应该改的地方：

- 不改变解析算法核心。
- 不改变数据保存策略。
- 不做完整编辑功能。
- 不接入 WebView。

验收标准：

- 课表视觉接近 `preview.html` 的清爽蓝色风格。
- 点击课程出现详情弹窗。
- 今天课程数量正确。
- 手机端可横向滚动。
- 平板端列宽更舒展。

测试重点：

- 长课程名不溢出。
- 课程块位置正确。
- loading、empty、error、success 状态切换。
- 横竖屏布局。

## 阶段 4：本地保存与编辑

目标：

- 保存导入结果。
- 支持手动编辑课程。
- 支持自定义课程颜色。
- 支持多学期管理。

改动范围：

- 新增 `storage/ScheduleRepository`。
- 新增 `storage/SettingsRepository`。
- 设计 JSON 保存格式。
- 增加编辑页面或编辑弹窗。
- 增加学期切换。

不应该改的地方：

- 不引入复杂数据库，除非 JSON 无法满足。
- 不改 PDF 解析主流程。
- 不做云同步。

验收标准：

- 重新打开 App 后能恢复上次导入课表。
- 用户可以修改课程名、时间、地点、教师、周次。
- 用户可以修改课程颜色。
- 多学期之间不会互相覆盖。

测试重点：

- 本地保存和读取。
- 编辑后周课表刷新。
- 数据版本兼容。
- 权限失效时仍能显示已保存结果。

## 阶段 5：导出、分享、提醒

目标：

- 导出图片。
- 分享课表。
- 课程提醒。
- 设置页面完善。

改动范围：

- 新增 `export/ScheduleImageExporter`。
- 新增 `export/SchedulePdfExporter`。
- 新增 `export/ShareHelper`。
- 使用系统分享面板。
- 增加提醒设置和通知权限处理。
- 完善设置页。

不应该改的地方：

- 不重做解析。
- 不引入大型 PDF 导出库。
- 不做社交关系链。
- 不做账号体系。

验收标准：

- 可以导出当前周课表图片。
- 可以分享导出的图片或 PDF。
- 设置页可以管理导出和提醒偏好。
- 提醒能按课程时间触发。

测试重点：

- 导出图片清晰度。
- 分享文件权限。
- 无课程时导出提示。
- 通知权限和提醒取消。
- 平板导出尺寸。
