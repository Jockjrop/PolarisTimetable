# Polaris课程表产品设计

## 1. 当前项目分析

### 已经实现的能力

当前项目是一个原生 Android Java 应用，核心能力已经跑通：

- 通过系统文件选择器导入 PDF 课表。
- 支持从外部应用以 `application/pdf` 打开课表文件。
- 使用 PDFBox Android 提取 PDF 文字及坐标。
- 根据星期列、节次标记、课程块文本解析课程。
- 以原生 View 动态绘制 1-11 节、周一到周六的横向课表。
- 手机端通过横向滚动查看完整周课表，平板端使用更宽的列宽。
- 在没有导入结果时展示一组示例课程，避免首页空白。
- 提供上一周、本周、下一周的基础切换入口。
- 提供底部导航的雏形：“课表 / 学习 / 我的”。

### MainActivity.java 当前职责

`MainActivity.java` 目前承担了过多职责：

- 页面搭建：用 Java 代码创建顶部标题、操作按钮、周次切换、课表网格、底部导航。
- 响应交互：处理导入 PDF、周次切换、按钮 Toast、课程点击。
- 文件导入：发起 `ACTION_OPEN_DOCUMENT`，读取文件名，保存 URI 权限。
- 解析调度：启动后台线程调用 `ScheduleParser.parse()`。
- 状态展示：显示“正在解析”“导入失败”“已导入”等简单状态。
- 课程绘制：计算课表宽高、节次高度、星期列宽、课程块位置。
- 示例数据：在没有真实课程时内置示例课表。
- 适配逻辑：根据 `smallestScreenWidthDp >= 600` 决定手机或平板尺寸。

这些职责未来应逐步拆分到 `ui`、`parser`、`model`、`storage`、`export` 等模块，但第一阶段不应该一次性大改。

### ScheduleParser.java 当前解析逻辑

当前解析流程是：

1. 初始化 PDFBox Android。
2. 用 `PDDocument.load()` 打开 URI 输入流。
3. 自定义 `PositionStripper extends PDFTextStripper`。
4. 在 `writeString()` 中读取 `TextPosition`，按 X 坐标排序。
5. 当同一行文字间距大于阈值时切成多个 `TextBlock`。
6. 清理空白字符，按页码、Y 坐标、X 坐标排序。
7. 查找包含“星期一”到“星期五”的文本块，计算每列中心点。
8. 如果星期列识别不完整，则用页面宽度估算列中心。
9. 用正则 `[(](\d+)-(\d+)节[)]` 找到节次和周次文本。
10. 根据节次文本块的 X 中心匹配最近星期列。
11. 向前查找附近的课程名文本块。
12. 向后收集同列同页的详情文本。
13. 从详情中提取 `场地:` 和 `教师:`。
14. 按星期、节次、课程名、周次去重。

该方案适合示例 PDF 这种文字型横向表格课表，但对多页延续、周六周日、其他课程、复杂周次、课程名换行、坐标偏移仍需要增强。

### Course.java 当前模型限制

当前 `Course` 是一个扁平不可变对象：

- 一门课只能有一个 `day`、`startSection`、`endSection`。
- `weeks` 是普通字符串，无法可靠判断某一周是否上课。
- 不支持一门课多个上课时间，例如同一课程周一 1-2 节、周四 3-4 节。
- 不支持单双周结构化表达。
- 不支持项目周、考试周、未知周次等非标准规则。
- 不支持解析置信度，无法提示用户哪些识别结果需要确认。
- `raw` 只保存详情片段，缺少 PDF 页码、坐标、原始文本块等纠错上下文。
- 缺少课程类型、校区、教学班、学分、来源文件、颜色等扩展字段。

### preview.html 视觉迁移方向

`preview.html` 是视觉原型，不应被 WebView 直接加载。可迁移到 Android 原生 UI 的元素包括：

- 清爽蓝色背景：用 `GradientDrawable`、自定义 `Drawable` 或主题色近似实现。
- 顶部今日概览：使用纵向 `LinearLayout` 或后续自定义 Header View。
- 统计卡片：用圆角背景 `TextView`/`LinearLayout` 承载“本周课程、实验/实践、当前周次”。
- 日期条：用横向 `LinearLayout` 或 `HorizontalScrollView` 承载星期按钮。
- 周课表：继续用 `FrameLayout` 绝对定位课程块，或提取为 `ScheduleBoardView`。
- 课程块：用原生圆角背景、按课程或星期分配颜色。
- 底部导航：保留原生底部三栏，不接入 Web。
- Toast/弹窗：课程详情应升级为原生 `Dialog` 或 `BottomSheet` 风格弹窗。

### 当前最需要优先优化的地方

1. 先稳定解析输出：增加诊断日志、失败原因、示例 PDF 测试。
2. 拆分 `MainActivity` 中的模型、解析和 UI 绘制职责。
3. 设计结构化数据模型，解决多时间、单双周、项目周和置信度问题。
4. 增加解析结果确认页，避免错误识别直接进入主课表。
5. 增加本地保存，避免每次启动都重新导入。
6. 完善手机和平板 UI 状态，包括 loading、empty、error、success。

## 2. 产品定位

Polaris课程表是一个面向学生的移动端课程表 App。它的核心价值是：导入教务系统 PDF 课表后，自动识别课程，并以漂亮、清晰、适配手机和平板的方式展示。

产品关键词：

- 轻量：不要求登录教务系统，先从 PDF 导入开始。
- 清晰：优先把当天和本周课程讲明白。
- 可信：解析结果可确认、可纠错、可追踪来源。
- 好看：保留 Polaris 清爽蓝色和卡片式课程块。
- 可继续开发：模型、解析、UI、导出、存储各自有清楚边界。

## 3. 目标用户

- 主要用户：高校学生，尤其是经常用 PDF 或截图保存课表的学生。
- 次要用户：班委、助教、需要分享课程安排的人。
- 设备场景：手机竖屏为主，平板横屏和竖屏为增强体验。

## 4. 核心使用流程

### 首次使用

1. 用户打开 App。
2. 首页显示示例课表和“导入 PDF”入口。
3. 用户选择教务系统 PDF。
4. App 显示解析中状态。
5. 解析成功后进入解析结果确认页。
6. 用户确认或稍后手动修正。
7. 保存并进入周课表。

### 日常查看

1. 打开 App 后进入首页/今日概览。
2. 顶部显示当前周次、日期、今天课程数量。
3. 用户查看今天课程列表或进入周课表。
4. 用户切换上一周、本周、下一周。
5. 点击课程块查看详情。

### 导出分享

1. 用户进入导出/分享页。
2. 选择导出本周、指定周或整学期。
3. 选择图片或 PDF。
4. App 生成预览并调用系统分享。

## 5. 核心功能

### 导入 PDF 课表

- 入口：顶部 `+` 按钮、空状态主按钮、设置页导入入口。
- 文件来源：系统文件选择器、外部 PDF 打开。
- 状态：选择文件、解析中、解析成功、解析失败、部分成功。
- 限制：第一阶段只支持文字型 PDF；扫描版 PDF 后续可作为 OCR 增强。

### 自动识别课程信息

必须识别：

- 课程名
- 星期
- 节次
- 周次
- 地点
- 教师

增强识别：

- 校区
- 教学班
- 课程类型：讲课、实验、实践、网络
- 来源页码和坐标
- 置信度

### 周课表视图

- 横轴：星期一到星期六，后续支持星期日。
- 纵轴：第 1-11 节。
- 手机：横向滚动周视图。
- 平板：优先铺满宽度，可同时展示更多天。
- 课程块按节次跨度自动拉高。
- 当前日期和今天所在列高亮。

### 本周 / 上一周 / 下一周切换

- 顶部显示当前周次。
- 切换后课程块根据 `WeekRule` 过滤。
- 单周、双周、项目周按当前周次判断是否显示。
- 当前没有课程时显示该周空状态，不清空全部数据。

### 今天课程概览

- 首页顶部展示“今天 N 节课”。
- 展示下一节课、上课地点、时间。
- 今日无课时显示轻量空状态。
- 支持点击课程进入详情弹窗。

### 课程详情弹窗

展示：

- 课程名
- 星期和节次
- 周次规则
- 地点和校区
- 教师
- 课程类型
- 原始 PDF 文本
- 解析置信度和问题提示

后续可加入“编辑”“复制地点”“添加提醒”。

### 解析失败提示

- 告知失败原因：非文字 PDF、没有识别到星期列、没有识别到节次、文件损坏等。
- 提供操作：重新选择 PDF、查看示例、反馈日志。
- 对部分成功情况，进入确认页并标记低置信度结果。

### 空状态示例课表

- 保留当前示例课表思想。
- 空状态不应像真实导入结果一样误导用户。
- 示例课程块可带“示例”角标或提示。
- 主按钮引导导入 PDF。

### 导出图片或 PDF

- 图片：导出当前周课表长图。
- PDF：导出可打印版周课表或整学期列表。
- 第一阶段只设计，不实现。
- 不引入大型依赖，优先用 Android Canvas 绘制图片；PDF 可后续用 Android 原生 `PdfDocument`。

### 分享课表

- 调用系统分享面板。
- 分享内容包括导出的图片/PDF和简单文本。
- 未来可加入“分享给同学的轻量卡片”。

### 设置页面

基础设置：

- 当前学期
- 当前周次
- 每天显示范围
- 周六周日显示开关
- 课程颜色策略
- 导出样式
- 解析日志开关

## 6. 后续增强功能

- 手动添加课程。
- 手动编辑识别错误的课程。
- 多学期课表。
- 课程提醒。
- 课程颜色自定义。
- 桌面小组件。
- 扫描版 PDF OCR。
- 教务系统模板适配。

## 7. 产品原则

- 先可用，再漂亮，再智能。
- 解析结果要可解释，不能只给“失败”。
- UI 以课程查看效率为第一目标，不做复杂社交功能。
- 第一阶段不迁移 Kotlin、Compose 或 Web。
- 不一次性重构全部代码，按阶段降低风险。
